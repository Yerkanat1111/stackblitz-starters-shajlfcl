GameVerse — мир видеоигр
GameVerse — адаптивный сайт-визитка о видеоиграх. Он объединяет три тематических раздела: обсуждения игровых проектов, информацию о релизах и сведения о будущих обновлениях.

Проект создан на HTML, CSS и JavaScript без сторонних библиотек и фреймворков.
Возможности
- Переключение темы. Пользователь может выбрать тёмную или светлую тему. Выбор сохраняется в localStorage, поэтому после повторного открытия страницы тема остаётся прежней.
- Три тематические карточки. На главной странице представлены обсуждения, последние релизы и ближайшие обновления.
- Адаптивная вёрстка. Сетка карточек перестраивается для небольших экранов, чтобы сайтом было удобно пользоваться на телефоне, планшете и компьютере.
- Анимации интерфейса. При наведении карточки приподнимаются, а элементы управления плавно меняют состояние.
- Прокрутка к началу страницы. Предусмотрена отдельная кнопка «Наверх», которая появляется после прокрутки.
- Визуальное оформление. Используются тёмная цветовая палитра, красно-розовые акценты, градиенты, полупрозрачные поверхности и декоративное свечение.
- Семантическая разметка. В структуре страницы используются header, main, section, article и footer.
Технологии
Технология	Назначение
HTML5	Структура и содержание страницы
CSS3	Цветовая схема, сетка, адаптивность и анимации
JavaScript	Переключение темы, сохранение настроек и управление кнопкой прокрутки
localStorage	Сохранение выбранной темы в браузере


Структура проекта
Минимальная структура проекта может выглядеть так:
GameVerse/
├── index.html       # Главная страница: HTML, CSS и JavaScript
├── README.md        # Описание проекта и инструкция по запуску
└── images/          # Изображения для карточек (если используются локальные файлы)
    ├── game1.jpg
    ├── game2.jpg
    └── game3.jpg
Если изображения подключены напрямую по ссылкам, папка images/ не обязательна. В таком случае адрес изображения указывается в атрибуте src соответствующего тега <img>.
Как запустить проект
Сборка и установка зависимостей не требуются.
1. Скачайте или клонируйте проект на компьютер.
2. Откройте папку проекта в редакторе кода, например Visual Studio Code.
3. Откройте файл index.html в браузере.
Для удобной разработки можно запустить проект через расширение Live Server в Visual Studio Code: откройте index.html и выберите Open with Live Server.

Если проект открыт в StackBlitz, используйте встроенный предпросмотр после загрузки файлов проекта.
Как изменить содержимое
Тексты карточек
Найдите в index.html блоки с классом card и измените заголовки и описания внутри них. Сейчас предусмотрены карточки:
- discussions — обсуждения игр;
- releases — последние релизы;
- updates — ближайшие обновления.
Изображения
Замените значение src у нужного тега <img> на адрес изображения или путь к локальному файлу, например:
<img src="images/game1.jpg" alt="Игровая сцена" />
Изображения лучше хранить в отдельной папке images/. Для каждого изображения указывайте содержательный alt, чтобы описать его пользователям, которые не могут его увидеть.
Цвета и оформление
Основные цвета находятся в CSS-блоке :root в начале таблицы стилей. Там объявлены переменные --bg, --text, --accent, --border и другие. Значения для светлой темы переопределяются в селекторе body.light-theme.
Тема сайта
Ключ сохранённой настройки в браузере — gameverse-theme. Значения dark и light обозначают выбранную тему.
Дальнейшее развитие
В качестве следующих улучшений можно добавить отдельные страницы или полноценные разделы с публикациями, поиск по играм, фильтрацию релизов по платформам, календарь обновлений и ссылки на официальные страницы игр.
Примечание
Сейчас GameVerse — демонстрационная главная страница. Карточки оформлены как тематические блоки; для полноценного сайта их можно связать с отдельными страницами или реальными материалами.
